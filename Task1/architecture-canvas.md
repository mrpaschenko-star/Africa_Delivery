# Architecture Canvas

| Секция | Решение |
|---|---|
| Проблема | Greenfield без команды рынка, оплаченная реклама и противоречивые обещания. Нужен контролируемый запуск, не копия Amazon за восемь недель |
| Ценность | Покупатель оформляет и оплачивает заказ; продавец видит подтверждённый баланс/план выплаты; CEO видит заказы и GMV |
| Измеримый MVP | Нигерия + Кения, 5000 SKU, 100 проверенных продавцов; 10k заказов/мес — расчёт, 1M покупателей — маркетинговая гипотеза |
| Архитектура | Go-модульный монолит; country cells, PostgreSQL, outbox/jobs, payment/logistics adapters; отдельные API/worker процессы |
| Ограничения | 15.10.2026; 6 контракторов; technical recurring ≤$5000/мес первые 6 мес; только monthly/Net45; строки >$500 через CFO |
| Драйверы | Законность/денежные инварианты → срок и cash → измеримая доступность → обратимое масштабирование |
| Данные | PII, заказы, ключи и backup внутри соответствующей страны; глобально только публичный каталог и обезличенные агрегаты |
| Качество | Каталог 99.9%; платежи: собственный приём 99.9%, внешний исход ≥99.5% за 15 мин; уведомления ≥99% за 5 мин. Предлагаемые SLO вместо неутверждённых 99.99% без деградации |
| Отложено | Своя логистика, кредит/кошелёк, ML/live-stream, три равноправных клиента, Kafka/Istio/40 сервисов. Kubernetes-exception до M6 |
| Риски | Неподписанные партнёры/Net45, локальные DC, store review, права на данные, выплаты и рост сверх оплаченной ёмкости |
| Путь развития | M1 sandbox → M2 limited pilot → M6 надёжность/решение о ЮАР → M12 5 стран и B2B; выделение сервисов по нагрузке/ownership |

Источники: [A1](../sources/artifact-01.md), [A3](../sources/artifact-03.md), [A5](../sources/artifact-05.md), [A6](../sources/artifact-06.md), [C01–C08](contradictions.md).

## Assumptions

Работа ведётся из учебной даты 12.08.2026. CFO/инвестор должны утвердить scope, SLO и исключения; законность и договоры являются обязательными gates. При отказе согласовать компромисс архитектор не обещает одновременное выполнение несовместимых условий. Публичный запуск страны без лицензированного PSP/разрешённого размещения запрещён.
