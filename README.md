## Решения для встречи

Спонсору предложено утвердить ограничение scope, SLO пилота вместо безусловных 99.99%, временное исключение по Kubernetes из CN-чек-листа и отказ от same-day settlement без обеспеченного финансирования. Эти согласования **не получены**. Закупочные, юридические и платёжные условия — gates до запуска; работа не объявляет инфраструктуру внедрённой или SLA доказанным.

## Assumptions

Учебная точка старта — 12.08.2026; восемь недель реализации — 17.08–11.10 плюс четыре дня на запуск. Входные артефакты и проверенные тарифы разных дат не смешиваются с фактическими результатами. Отсутствующие приложения А/Б/В заменены явно обозначенными рабочими шаблонами. Источники решений: A1/A6/A7 и [C01–C08](Task1/contradictions.md).
