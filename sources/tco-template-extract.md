# Проверка исходного TCO-шаблона

Прочитан XLSX из приложенного архива, без изменения оригинала. Листы: «Инструкция», «Допущения», «TCO».

| Лист / ячейка | Исходное значение | Решение |
|---|---|---|
| Инструкция!C18 | Проверка CFO ($9k/мес на облако) | В конфликте C05 приоритет письму CFO |
| Инструкция!C21 | $9 000/мес на облако на старте | Заменено $5000 на все technical recurring |
| Допущения!C18 | 9000 | Monthly проверяет каждый месяц, включая SaaS/messages |
| Допущения!H18 | «Ограничение из письма CFO» | Атрибуция неверна относительно A6 P11 |
| TCO!E64 | IF(E15/12<='Допущения'!$C$18,…) | Среднегодовая проверка не заменяет помесячный cap |

Использованы структура затрат и финансовые метрики шаблона; добавлены отдельные варианты A/B/C, помесячные расходы, T0, overbuild/underbuild. [Оригинальное требование CFO](artifact-06.md#p11), [модель](../Task2/tco-model.xlsx).
