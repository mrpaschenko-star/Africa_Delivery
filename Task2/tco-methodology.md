# Методика TCO и пределы расчёта

[tco-model.xlsx](tco-model.xlsx) содержит Summary, Assumptions, Monthly, TCO-A/B/C и Availability. Жёлтые ячейки — входы, остальные вычисляются; все суммы USD. Сохранены шесть блоков исходного шаблона: инфраструктура, лицензии, транзакции, люди, запуск, риск. Ошибочный лимит шаблона $9000 заменён $5000 ([A6](../sources/artifact-06.md), C05).

## Формулы

Cash TCO = compute + SaaS + payment + SMS + WhatsApp + courier + ФОТ + on-call + management + T0 + audit + 15% резерв. GMV = заказы × средний чек; GMV не выручка маркетплейса. Архитектурный TCO исключает переменные платежи, сообщения и курьера вместе с их резервом. NPV = T0 с резервом в момент 0 + годовые операционные потоки / (1+20%)^год. Первый год — 12 месяцев после запуска; prelaunch выделен T0, повторно не начисляется.

Cost/order на старте и M12 — run-rate данного месяца: регулярные расходы, люди, комиссии и доставка с резервом / заказы. Он не включает T0 и ежегодный audit; полная пятилетняя стоимость на заказ включает их и составляет A $3.29, B $3.32, C $3.72. Рост заказов, а не магическая экономия облака, снижает стоимость от $6.72 до $3.50 у A.

## Assumptions

| Вход | План |
|---|---|
| Заказы по годам | 515 000; 1.8M; 4M; 7M; 10M |
| Пользователи на конец года | 1.2M; 2M; 4M; 7M; 10M зарегистрированных |
| Средний чек | $25; $26; $27; $28; $29 |
| M1…M12, тысяч заказов | 10,15,20,20,25,25,40,50,60,70,80,100 |
| Платежи | 60% NG × 2.30% + 40% KE × 1.95% = 2.16% GMV; договоры не получены |
| Сообщения | 2 SMS×$0.02 + 1 WhatsApp×$0.01 = $0.05/заказ; OTP и retries входят в лимит |
| Доставка | $2/заказ, условная партнёрская себестоимость, не рыночная котировка |
| ФОТ | Product/QA $48k, platform $60k в год; on-call $3k/FTE; management $36k/год |
| Инфляция / ФОТ / дисконт | 5% / 8% / 20%; infra по плану ёмкости без двойного начисления инфляции |
| Резерв / downtime в base | 15% прямых затрат / выключен, только stress-сценарий |

После M6 бюджет требует нового утверждения: A M12 $12 995/мес с сообщениями и резервом. Шесть человек остаются в первые шесть месяцев, восемь во вторые; 5.5 product +1.5 platform — среднегодовые FTE, не найм половины человека. Источники ставок: оценка архитектора, [A6](../sources/artifact-06.md), тарифы [E01–E04](../sources/README.md).

## Стоимость ошибки и чувствительность

Overbuild: фактически 50k зарегистрированных, 10k заказов/мес; фиксированные T0+6 месяцев A $270k, B $287.8k, C $1.029M. C−A=$759k до резерва. Это разница обязательств и потраченного труда, не вся сумма оборудования, которую обязательно невозможно вернуть. Если расторгнуть договоры, cash loss меньше. Underbuild: выделение перегруженного модуля из A — 10 engineer-month×$4k + $15k параллельная работа + $5k миграционное тестирование = $60k ($69k с резервом), если границы сохранены.

При росте первых месяцев до 50k заказов: (2850+150+2500)×1.15=$6325, лимит уже нарушен. При удвоении цены SMS у 25k заказов: (3000+2250)×1.15=$6037.50. Поэтому тарифы и лимиты OTP — release gate, не бесплатный запас. Платёжная комиссия +0.5 п.п. добавляет $0.125 на заказ при AOV25 до резерва. Снижение AOV повышает долю фиксированных комиссий: проверить все методы, минимальный чек и payout batching.

Собственная логистика: 4 инженера×6 месяцев×$4k=$96k разработки, без диспетчеров, транспорта и поддержки; интеграция 2 engineer-month=$8k внутри T0. Высвобождение $88k и четырёх инженеров важнее гипотетической экономии $2/заказ: software не устраняет физическую доставку. Самостоятельная платёжная лицензия не помещается в 8 недель ([A3](../sources/artifact-03.md)); стоимость прямого M-Pesa сопоставлена в [ADR-004](../Task5/adr-004-payment-provider.md).

Availability отдельно считает стоимость дополнительных девяток; $12k/мин — peak revenue stress, не ожидаемая денежная потеря, не включается в base TCO. Проверка формул: [результат](../review/tco-checks.json). Валютный риск локальных счетов и quoted support покрывает лишь 15% резерв; превышение требует CFO, не скрытого уменьшения SLA.
