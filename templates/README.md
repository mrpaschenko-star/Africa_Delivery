# Рабочие шаблоны

Приложения А/Б/В, на которые ссылается задание, не приложены. Использованы собственные [ADR](adr-template.md), [Vision](vision-template.md) и [QAS](qas-template.md); это не реконструкция неизвестного текста приложений.

FMEA сохраняет поля и шкалу предоставленного шаблона, Data Residency — обязательные поля задания и разделы исходного шаблона с исправлением спорных допущений. TCO сохраняет шесть блоков и пятилетний горизонт XLSX-шаблона, дополняя их помесячным бюджетом и расчётом ошибки. Причины адаптации — [источники](../sources/README.md).
